# CHARACTER REVIEW WORKFLOW

Status: Canon

## Purpose

Provide a repeatable review process before a character becomes Production Locked.

## Review Stages

1. Historical Plausibility Review
2. Character Architecture Review
3. Visual Style Review
4. Silhouette Review
5. Expression Review
6. Costume Review
7. Canon Review
8. Approval

## Character Questions

- Does the design communicate personality?
- Does the age read correctly?
- Does the silhouette read instantly?
- Does the costume support story and social status?
- Does the character fit Poetic Realism?

## Neeltje Rule

Neeltje must always read as an elderly woman (70+).

## Hilda Rule

Hilda must never drift into generic fantasy heroine design.

## Jan Rule

Jan must remain recognizable across all ages, poses and costume variations.

## Output

Approved Character Lock Package.
