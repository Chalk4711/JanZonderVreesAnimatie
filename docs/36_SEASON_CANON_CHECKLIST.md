# SEASON CANON CHECKLIST

Status: Canon

## Purpose

Provide a final quality gate before approving episodes, assets or season packages.

## Story

- Supports season thesis
- Supports character arcs
- Supports themes

## Character

- No character drift
- No age drift
- No personality drift

## Visual

- Fits Poetic Realism
- Fits 40/40/20 formula
- Fits Visual Style Bible

## Cinematography

- Uses motivated camera language
- Supports emotional storytelling

## Sound

- World first, music second
- Consistent sonic identity

## Worldbuilding

- Consistent geography
- Consistent locations

## Canon

- Consistent with Canon Decision Log
- Consistent with Project Master Context

## Approval

Only content that passes all categories can be considered season-canon.
