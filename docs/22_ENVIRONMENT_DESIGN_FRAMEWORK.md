# ENVIRONMENT DESIGN FRAMEWORK

Status: Canon

## Philosophy

Environment design is storytelling.

Locations must communicate emotional meaning before dialogue begins.

## Emotional Zones

### Home

Examples:
- Neeltje's Fish Shop
- Krabbenstraatje

Keywords:
Warmth, belonging, memory, safety.

### Community

Examples:
- Fish Market
- Grote Markt

Keywords:
Life, work, identity, commerce.

### Adventure

Examples:
- Harbor
- Scheldt

Keywords:
Possibility, movement, uncertainty.

### Transformation

Examples:
- Free Forest

Keywords:
Mystery, growth, danger, wonder.

## Design Layers

Every location should communicate:

1. Function
2. History
3. Social class
4. Emotional role
5. Story potential

## Environment Checklist

- Visually distinctive
- Historically plausible
- Emotionally meaningful
- Recognizable silhouette
- Unique sound identity
- Supports camera storytelling

## Canon Rule

Locations should become emotionally recognizable to the audience in the same way recurring characters do.
