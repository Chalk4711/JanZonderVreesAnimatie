# ASSET APPROVAL WORKFLOW

Status: Canon

## Purpose

Provide a repeatable review system for characters, environments, props, shots and promotional material.

## Review Stages

1. Draft
2. Internal Review
3. Canon Check
4. Revision
5. Approval
6. Production Lock

## Canon Check Questions

- Does it fit the Project Master Context?
- Does it fit the Character Bible?
- Does it fit the Visual Style Bible?
- Does it fit the Cinematography Bible?
- Does it fit the Sound Bible?
- Does it fit the Canon Decision Log?

## Rejection Criteria

- Character drift
- Age drift
- Costume drift
- Visual canon violations
- Emotional inconsistency
- Generic fantasy contamination

## Approval Rule

Assets become production references only after passing canon review.

## Final Principle

Consistency creates trust. Trust creates immersion.
