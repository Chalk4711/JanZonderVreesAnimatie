# STORY ARCHITECTURE BIBLE

Status: Canon Draft

## Core Rule

The series must never feel like: "and then another adventure happened."

It must feel like: every event changes a character.

## Character Over Plot

The primary engine is:

Character -> Choice -> Consequence -> Growth

Plot is valuable only when it pressures character.

## The Jan Rule

Every episode must answer:

How does this change Jan?

## The Hilda Rule

Every episode must reveal either a strength, contradiction or vulnerability in Hilda.

## The Neeltje Rule

Every episode involving home must shift Jan and Neeltje's relationship in some way.

## Emotional Architecture

Every major sequence should have three levels:

1. What happens?
2. What does the viewer feel?
3. What changes?

## Scene Success Criteria

A scene is successful if it advances at least one of:

- character relationship;
- inner conflict;
- theme;
- world understanding;
- plot consequence.

## Opening Sequence Canon

The opening movement should introduce the world before the hero:

Scheldt -> Harbor -> Fish Market -> Krabbenstraatje -> Neeltje's fish shop -> dried plaice sign -> attic window -> Jan.

Meaning:

World -> Community -> Family -> Person.

This is stronger than starting directly with Jan because it roots him emotionally in place and community.

## Adventure Rule

Adventure is the surface. Transformation is the purpose.

## Hidden Theme

Letting go is the deep theme beneath courage. Jan, Hilda, Neeltje and Dokus each experience a different form of letting go.
