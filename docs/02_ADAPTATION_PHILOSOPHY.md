# ADAPTATION PHILOSOPHY

Status: Canon v1

## Core Principle

This project is not a museum reconstruction.
It is not a fantasy reinterpretation.

It is historical cinema.

## Authenticity Framework

Authenticity is the foundation.
Emotion is the priority.

## Allowed Stylization

Controlled stylization is permitted when it improves:

- emotional clarity;
- visual readability;
- storytelling;
- cinematography.

## Forbidden Directions

- generic fantasy aesthetics;
- modernized medieval culture;
- Disney-style simplification;
- grimdark realism;
- historical details that weaken story.

## Visual Formula

40% historical reality
40% cinematic readability
20% emotional enhancement

## Character Rule

Character truth outranks historical trivia.

## World Rule

The audience should feel that medieval Flanders lived like this, even when selective stylization is applied.

## Canon Goal

Create a believable medieval world that serves timeless human stories.
