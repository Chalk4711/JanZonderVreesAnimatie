# PRODUCTION MAP BIBLE

Status: Canon Draft

## Purpose

Create a spatially coherent world that supports storyboarding, animation, AI generation and continuity.

## Core Principle

The audience should gradually feel capable of navigating Jan's world.

## Primary Locations

### Scheldt
Represents change and possibility.

### Harbor
Represents freedom, trade and adventure.

### Fish Market
Represents community and daily life.

### Krabbenstraatje
Represents neighborhood and belonging.

### Neeltje's Fish Shop
Represents home, memory and safety.

### Grote Markt
Represents civic life and public identity.

### City Gate
Represents transition between known and unknown.

### Stansen Farm
Represents work, responsibility and family structure.

### Free Forest
Represents mystery, transformation and growth.

## Opening Route Canon

Scheldt -> Harbor -> Fish Market -> Krabbenstraatje -> Fish Shop -> Plaice Sign -> Attic Window -> Jan.

## Production Rule

All future maps, environment concepts and establishing shots should remain consistent with this spatial framework.

## Long-Term Goal

Develop a definitive production map for Season 1 that can be used by storyboard artists, AI agents and environment designers.
