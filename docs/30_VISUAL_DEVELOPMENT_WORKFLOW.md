# VISUAL DEVELOPMENT WORKFLOW

Status: Canon

## Goal

Move from concept art to production-ready visual assets while preserving canon consistency.

## Stage 1
Reference Gathering

- Historical references
- Flemish references
- Material references
- Lighting references

## Stage 2
Concept Exploration

Generate multiple concepts.
Explore silhouette and mood.

## Stage 3
Canon Evaluation

Check against:
- Project Master Context
- Visual Style Bible
- Character Architecture
- Canon Decision Log

## Stage 4
Refinement

Improve strongest concepts.

## Stage 5
Production Candidate

Prepare asset package.

## Stage 6
Character or Environment Lock

Asset becomes approved production reference.

## Core Rule

Exploration is encouraged.
Canon drift is not.
