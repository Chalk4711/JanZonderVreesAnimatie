# INTEGRATED AI PROMPT BIBLE

Status: Canon v2

## Purpose

Defines how AI systems generate images, concepts, environments, soundscapes, animation prompts and story materials while remaining canon-consistent.

## Canon Hierarchy

1. PROJECT_MASTER_CONTEXT
2. CANON_DECISION_LOG
3. CHARACTER_BIBLE and CHARACTER_ARCHITECTURES
4. VISUAL_STYLE_BIBLE
5. CINEMATOGRAPHY_BIBLE
6. SOUND_BIBLE
7. Prompt Bible

Never contradict a higher-level document.

## Master Prompt Rule

Every prompt should answer:

- Who?
- Where?
- Why?
- Emotional state?
- Visual intention?
- Camera intention?
- Canon references?

## Character Prompt Template

## Character Lock Rule

Do not redesign approved characters.
Refine only.

Always use approved canon assets as reference inputs whenever possible.

## Image Prompt Keywords

- Poetic realism
- Historical Flemish atmosphere
- Premium animation quality
- Painterly cinematic lighting
- Strong silhouette
- Emotional readability
- Natural materials
- Historically plausible costume

## Negative Prompt Principles

Avoid:

- fantasy armor
- generic Disney styling
- modern clothing
- glamourized elderly characters
- anime redesigns
- medieval RPG aesthetics
- inconsistent age portrayal

## AI Validation Checklist

Before accepting output:

1. Does it feel Flemish?
2. Does it fit Poetic Realism?
3. Does it fit the Character Bible?
4. Does it fit the Visual Style Bible?
5. Does it fit the Cinematography Bible?
6. Does it fit the Sound Bible?
7. Does it feel like Jan Zonder Vrees?

If not, revise before approval.

## Final Rule

Consistency is more important than novelty.
A beautiful asset that breaks canon should be rejected.
