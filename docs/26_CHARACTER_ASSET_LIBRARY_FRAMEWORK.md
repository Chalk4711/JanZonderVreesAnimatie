# CHARACTER ASSET LIBRARY FRAMEWORK

Status: Canon

## Purpose

Standardize character assets for AI, storyboard, animation and production workflows.

## Required Assets Per Character

1. Canon Candidate
2. Hero Portrait
3. Turnaround Sheet
4. Expression Sheet
5. Pose Sheet
6. Costume Sheet
7. Prop Sheet
8. Character Lock Approval

## Metadata

Every asset should include:

- Character name
- Version number
- Status
- Date
- Canon approval state

## Approval States

Draft
Review
Candidate
Approved
Production Locked

## Character Lock Rule

Production Locked characters may only receive refinement updates.
