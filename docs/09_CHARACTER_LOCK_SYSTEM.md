# CHARACTER LOCK SYSTEM

## Goal
Ensure long-term character consistency across image generation, animation, storyboards and AI agents.

## Character Lock Workflow
1. Canon Candidate
2. Hero Portrait
3. Production Turnaround
4. Expression Sheet
5. Pose Sheet
6. Costume Breakdown
7. Prop Sheet
8. Production Lock

## Production Lock Criteria
- Strong silhouette
- Historical plausibility
- Emotional readability
- Consistent age portrayal
- Visual uniqueness
- Fits series visual language
